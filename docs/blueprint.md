# **App Name**: EcoGenius

## Core Features:

- Eco-Friendly Suggestion Generation: Generate personalized eco-friendly suggestions based on user's lifestyle, using a tool that analyzes potential environmental impacts of different choices.
- Energy Consumption Tracking: Allow users to track their energy consumption via manual input. Initially just tracking, not trying to connect to any APIs.
- Green Alternative Recommendations: Recommend green alternatives for common products and services based on user preferences and location.
- Personalized Dashboard: Display key environmental metrics and personalized recommendations on a clean, intuitive dashboard.
- Profile Customization: Allow users to create and customize profiles with relevant information for personalized suggestions.

## Style Guidelines:

- Primary color: Forest green (#388E3C), symbolizing nature and sustainability.
- Background color: Light beige (#F5F5DC), providing a natural, earthy feel with brightness suitable for a light scheme.
- Accent color: Earthy orange (#D35400), drawing attention to CTAs.
- Body and headline font: 'PT Sans', a modern sans-serif with a balance of warmth and modernity.
- Use minimalist, line-based icons related to environmental themes.
- Maintain a clean, spacious layout to reduce visual clutter and enhance user experience.
- Incorporate subtle transitions and animations to provide feedback and improve engagement.
